# ADR-0001 — Один Engine, два мира

- **Статус:** Accepted
- **Дата:** 2026-09-28 (ТЗ v1.0)

## Контекст

Pigeon существует в двух средах: на реальном рабочем столе и в процедурном браузерном городе.
Два независимых продукта означали бы два голубя с расходящимся поведением.

## Решение

```
Pigeon Engine
├── Desktop World
└── Browser City World
```

Личность, потребности, настроение, память, отношения, Life Story, прогресс и выбор намерений —
общие. Мир подключается через `IWorldAdapter`.

## Последствия

- Ядро не зависит от конкретного мира; см. уточнение границы в ADR-0013.
- Ядро должно работать во всех хостах, включая браузер (ADR-0014).
