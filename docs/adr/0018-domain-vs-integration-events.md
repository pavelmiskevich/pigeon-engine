# ADR-0018 — Доменные и интеграционные события раздельно

- **Статус:** Proposed
- **Дата:** 2026-09-30

## Контекст

Единый `IEventBus` из v1.0 (только `PublishAsync`) использовался и для событий внутри тика
симуляции, и для Kafka. Требования у них противоположные: детерминизм и синхронность против
асинхронной at-least-once доставки с версионируемой схемой.

## Решение

- `IDomainEventDispatcher` — внутри процесса и тика, синхронно, упорядоченно, с подпиской.
- `IIntegrationEventPublisher` — наружу: на Desktop — в локальный журнал, в Online —
  transactional outbox в PostgreSQL → relay в Kafka.

## Последствия

- Контракты интеграционных событий версионируются и обратно совместимы.
- Доменные события меняются свободно вместе с кодом.
