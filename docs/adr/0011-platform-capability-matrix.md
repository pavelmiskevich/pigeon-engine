# ADR-0011 — Матрица возможностей платформ и уровни деградации

- **Статус:** Accepted
- **Дата:** 2026-09-30

## Контекст

Главная механика Desktop требует геометрии чужих окон, z-order, глобального курсора и окна
поверх всех. Windows и X11 это дают, macOS — с оговорками, Wayland — намеренно нет (на GNOME
клиент даже не может встать поверх всех окон). Без явной модели код начнёт либо имитировать
данные (нарушение ADR-0002), либо ломаться.

## Решение

1. Движок оперирует **возможностями** C1–C20, а не типом ОС. Их определяет `ICapabilityProbe`
   во время работы.
2. По возможностям выбирается **уровень опыта**: L3 Full Desktop World, L2 Screen World,
   L1 Window Mode, L0 Background.
3. Поведение без нужной возможности получает оценку 0; данные не имитируются.
4. Потеря возможности на лету — доменное событие, на которое голубь реагирует.
5. Уровни поддержки платформ: Tier 1 — Windows; Tier 2 — macOS, X11; Tier 3 — Wayland
   (порядок — Proposed, вопрос Q4 в ТЗ).

Детали: [capability-matrix.md](../platform/capability-matrix.md).

## Последствия

- Нужна утилита `pigeon-probe` (MVP-0, S0.3); она же — инструмент для баг-репортов.
- Каждая комбинация «платформа × уровень» покрывается тестами адаптера с фейковыми источниками.
- Пользователь видит текущий уровень и что недоступно.
