# ADR-0020 — Privacy scope v1

- **Статус:** Proposed
- **Дата:** 2026-09-30

## Контекст

Уровни Clipboard, Screen, Voice и ToolExecution из v1.0, по-видимому, унаследованы от
Desktop AI Pet 2.0. Голубю они не нужны и противоречат принципу «не превращать в AI-assistant».
Заголовки окон содержат чувствительные данные (темы писем, названия документов) и служат
каналом prompt injection.

## Решение

- Уровни v1: None, Metadata (вкл.), Application (вкл., только локально), Window/заголовки (выкл.).
- Clipboard, Screen, Voice, ToolExecution исключены из scope; вернуть их можно только отдельным ADR.
- В журнал не пишутся заголовки и пути. Во внешние провайдеры уходят только категории приложений
  и агрегаты.
- Developer Mode показывает точный payload каждому провайдеру.
- Ответ провайдера — строго структурированный, только выбор из переданного списка.

## Последствия

- Policy Engine для инструментов не реализуется до появления первого инструмента.
- На macOS разрешение Screen Recording не запрашивается.
