# ADR-0012 — MVP-0 до MVP-1

- **Статус:** Accepted
- **Дата:** 2026-09-30

## Контекст

Самые дорогие ошибки проекта — технологические: неверный стек оверлея, нереализуемая на
платформе механика, недетерминированное ядро, несовместимое с браузером. Их нельзя исправить
после того, как на них написано ядро.

## Решение

Перед MVP-1 выполняется MVP-0: набор ограниченных по времени прототипов (spike) и каркас
репозитория. Прототипы живут в `spikes/` и в `src/` как есть не переносятся.

План и критерии выхода: [roadmap/mvp-0.md](../roadmap/mvp-0.md).

## Последствия

- Задачи MVP-1 заводятся только после выхода из MVP-0.
- Бюджеты производительности ТЗ §37 подтверждаются измерениями.
