# ADR-0002 — Desktop использует реальный мир

- **Статус:** Accepted; уточнено в ТЗ v1.1
- **Дата:** 2026-09-28, уточнение 2026-09-30

## Решение

> Никакого невидимого виртуального города на Desktop.

Desktop World состоит только из объектов, которые реально существуют на рабочем столе или
доступны через метаданные ОС.

## Уточнение v1.1

1. Запрещены **невидимые** симулируемые объекты: окна, машины, еда, которых пользователь не
   видит.
2. **Видимые** объекты оверлея, созданные пользователем или голубем (крошки, помёт, перо),
   допустимы: для пользователя они существуют так же, как сам голубь. Их число и время жизни
   ограничены (ТЗ §8.7).
3. Данные, которые платформа не даёт (позиции окон, курсор на Wayland), **не имитируются** —
   понижается уровень опыта (ADR-0011).

## Последствия

- Hunger на Desktop удовлетворяется крошками пользователя или «перекусом за экраном».
- Поведение без нужной возможности не выбирается.
