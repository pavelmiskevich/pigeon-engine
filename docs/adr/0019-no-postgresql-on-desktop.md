# ADR-0019 — Нет PostgreSQL на Desktop

- **Статус:** Proposed; заменяет часть ADR-0005 про «optional advanced provider Desktop»
- **Дата:** 2026-09-30

## Контекст

Опциональный PostgreSQL на Desktop удваивает матрицу тестов persistence и миграций. Выгоды для
обычного пользователя он не даёт, а для синхронизации нужен серверный API, а не прямое
подключение к БД.

## Решение

Desktop хранит данные только в SQLite. Связь с сервером (синхронизация, перелёт в город) — через
API Online Edition.

## Последствия

- `Pigeon.Persistence.PostgreSql` используется только сервером.
- Опытным пользователям остаётся экспорт `.pigeon` и прямой доступ к файлу SQLite.
