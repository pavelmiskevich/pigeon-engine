# ADR-0009 — AI Safety

- **Статус:** Accepted
- **Дата:** 2026-09-28

## Решение

> AI не получает прямой доступ к OS.

## Последствия

- В v1 у AI нет инструментов: советник выбирает только из переданного списка намерений
  (ТЗ §17, §33).
- Текст из ОС — недоверенные данные (prompt injection); scope данных — ADR-0020.
