# ADR-0003 — Local-First

- **Статус:** Accepted
- **Дата:** 2026-09-28

## Решение

> Desktop работает без собственного backend.

Все механики Desktop, включая детерминированный AI, память и Life Story, работают без сети.
Сетевые провайдеры (Jev, Cloud LLM, синхронизация) — опциональны.

## Последствия

- Сетевые провайдеры обязаны иметь локальный fallback (ADR-0015).
- Синхронизация с облаком — отдельная опциональная функция (MVP-6), не условие работы.
