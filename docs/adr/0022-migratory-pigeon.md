# ADR-0022 — Перелётный голубь: один голубь, всегда в одном мире

- **Статус:** Proposed
- **Дата:** 2026-10-07

## Контекст

ADR-0001 обещает «один голубь, два мира», но не говорит, как голубь связан с обоими мирами.
Варианты:

1. два разных голубя — просто, но теряется главная идея;
2. один голубь одновременно в двух мирах — ломает иллюзию существа и требует слияния состояний
   с конфликтами;
3. один голубь, который **перелетает** между мирами.

## Решение

Голубь всегда находится ровно в одном мире. Дом — Desktop, город — куда он улетает.

- Отлёт — по просьбе пользователя или по решению самого голубя (скука, долгое отсутствие
  пользователя, личность).
- Если открыт Browser Edition, голубь живёт в городе вживую.
- Если в город никто не смотрит, прогулка рассчитывается локально как детерминированная
  экспедиция: `(снимок, seed, длительность) → события, воспоминания, находки`.
- По возвращении голубь приносит находку и записи в Life Story.

**Единственный писатель:** мир, где сейчас голубь, владеет его состоянием через ограниченную по
времени аренду. Перелёт — передача снимка `.pigeon` (ADR-0017) и журнала после него. Если
сессия в городе оборвалась, аренда истекает и голубь возвращается домой с последним
подтверждённым состоянием.

Подробно: ТЗ §25.1.

## Последствия

- Нет слияния состояний и конфликтов синхронизации.
- Перелёт работает без сети (экспедиция), поэтому local-first (ADR-0003) сохраняется.
- В город уходит только состояние голубя; воспоминания о рабочем столе — категориями, без имён
  приложений и заголовков (ADR-0020).
- Этапы: экспедиция без Browser — MVP-2; живой перелёт — MVP-4; между устройствами — MVP-5/6.
