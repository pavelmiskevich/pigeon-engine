# ADR-0021 — Стек отрисовки Desktop

- **Статус:** Pending — решение по итогам MVP-0, S0.2
- **Дата:** 2026-09-30

## Контекст

Нужен прозрачный click-through always-on-top оверлей без фокуса на Windows, macOS, X11 и Wayland
(layer-shell), с корректной работой при смешанном DPI и минимальными CPU и RAM.

## Кандидаты

| Кандидат | За | Против |
|----------|----|--------|
| Avalonia 12 + нативный interop | Один UI-стек и для настроек; нативный Wayland-бэкенд в 12.1 | Click-through по форме и layer-shell — своим interop; Wayland-бэкенд экспериментальный; память |
| Тонкий нативный слой окна + SkiaSharp | Полный контроль над окном и потреблением | Больше платформенного кода |
| SDL3 / GLFW через биндинги | Готовые transparent/passthrough/floating окна | Нет layer-shell; ограниченный контроль |

## Критерии

Качество click-through, CPU и RAM в покое и в движении, DPI и смена мониторов, трудоёмкость
поддержки на каждой платформе, поддержка Wayland layer-shell.

## Решение

_Заполняется по результатам S0.2 с таблицей измерений._
