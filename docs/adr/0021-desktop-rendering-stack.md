# ADR-0021 — Стек отрисовки Desktop

- **Статус:** Proposed — по итогам замеров S0.2, ждёт подтверждения владельца
- **Дата:** 2026-09-30, решение предложено 2026-11-04

## Контекст

Нужен прозрачный click-through always-on-top оверлей без фокуса на Windows, macOS, X11 и Wayland
(layer-shell), с корректной работой при смешанном DPI и минимальными CPU и RAM.

## Кандидаты

| Кандидат | За | Против |
|----------|----|--------|
| Avalonia 12 + нативный interop | Один UI-стек и для настроек; нативный Wayland-бэкенд в 12.1 | Click-through по форме и layer-shell — своим interop; Wayland-бэкенд экспериментальный; память |
| Тонкий нативный слой окна + SkiaSharp | Полный контроль над окном и потреблением | Больше платформенного кода |
| SDL3 / GLFW через биндинги | Готовые transparent/passthrough/floating окна | Нет layer-shell; ограниченный контроль |

## Критерии

Качество click-through, CPU и RAM в покое и в движении, DPI и смена мониторов, трудоёмкость
поддержки на каждой платформе, поддержка Wayland layer-shell.

## Решение

> Оверлей Desktop — **тонкий нативный слой окна на каждую ОС + отрисовка SkiaSharp** (кандидат B).
> Avalonia остаётся кандидатом для окна настроек, отдельно от оверлея.

Замеры на эталонной машине (Core Ultra 7 258V, 32 ГБ, экран 144 Гц, масштаб 175 %, Windows 11),
подробности — [docs/research/desktop-overlay.md](../research/desktop-overlay.md):

| Показатель | A. Avalonia 12 | B. Win32 + SkiaSharp | Бюджет ТЗ §37 |
|------------|---------------:|---------------------:|--------------:|
| CPU, голубь сидит (всего CPU) | 1.8–2.1 % | 0.3–0.4 % | ≤ 0.5 % |
| CPU, голубь в движении (всего CPU) | 4.9–5.5 % | 1.6 % | ≤ 2 % |
| Working set | 137–144 МБ | 31–33 МБ | ≤ 150 МБ |
| Старт до первого кадра | 1.1–1.7 с | 0.15 с | ≤ 3 с |
| Click-through | переключение стиля по курсору, таймер 60 Гц | попиксельный, средствами ОС | — |

Обоснование:

- только B укладывается в бюджеты CPU и памяти, причём с запасом;
- попиксельный click-through без опроса курсора надёжнее: нет гонки между движением курсора и
  переключением стиля окна;
- layer-shell на Wayland и `NSPanel` на macOS в любом случае требуют своего interop. Avalonia
  здесь не экономит платформенный код, а добавляет свой слой поверх.

## Последствия

- На каждую ОС пишется своё окно: Win32 layered window, `NSPanel`, X11 ARGB-visual + XShape,
  Wayland layer-shell. Код отрисовки голубя (SkiaSharp) общий. Окно Windows из прототипа —
  ~250 строк.
- Бюджеты ТЗ §37 подтверждены как достижимые на Windows. Для других ОС они проверяются, когда
  там появится окно (MVP-1, MVP-2).
- Два монитора с масштабом 175 % и 100 % проверены: размер голубя верный на обоих, в момент
  пересечения границы размер меняется рывком — сглаживается в MVP-1. Окно настроек не проверено.
