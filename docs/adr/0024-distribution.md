# ADR-0024 — Дистрибуция и обновления

- **Статус:** Accepted (2026-11-05)
- **Дата:** 2026-11-04, принято 2026-11-05

## Контекст

Desktop Edition ставится на Windows (MVP-1), macOS и Linux (MVP-2). Нужны установщик и
автообновление. Автозапуск — только по согласию (ТЗ §4.4).

Подпись кода нужна только для того, чтобы система не предупреждала при установке; на работу
приложения она не влияет. Платная подпись — это годовые расходы и договор с иностранными
сервисами (Azure Artifact Signing, Apple Developer Program, удостоверяющие центры). Владелец решил
обойтись без неё.

## Решение

> Установщик и автообновление — **Velopack** (MIT, бесплатный) на всех трёх ОС. **Платной подписи
> кода нет.** Расходов на дистрибуцию нет.

| ОС | Формат | Обновление | Подпись | Что видит пользователь при установке |
|----|--------|-----------|---------|--------------------------------------|
| Windows | установщик Velopack (`Setup.exe`), ставится в профиль пользователя без прав администратора | Velopack, дельта-пакеты | нет | SmartScreen «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае»; на каждую новую версию |
| macOS | `.app` от Velopack, `LSUIElement` | Velopack | ad-hoc (бесплатная, без неё Apple Silicon не запускает программу) | «Не удаётся проверить разработчика» → Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»; один раз |
| Linux | AppImage от Velopack | Velopack (самообновляемый AppImage) | не нужна | ничего |

- **Инструкция по установке** со снимками экрана для Windows и macOS идёт вместе с релизом.
- **Антивирусы** к неподписанным программам иногда подозрительнее. Ложные срабатывания отправляются
  производителям антивирусов на проверку, это бесплатно.
- **Обновления** раздаются с GitHub Releases: Velopack читает их напрямую. Velopack умеет и любой
  статический хостинг, поэтому от GitHub можно уйти без изменений в приложении.
- **Linux, другие форматы.** `.deb` и Flatpak — позже, по запросу пользователей. Для Flathub нужно
  явное разрешение на распространение: у проекта нет лицензии.
- **Автозапуск** — opt-in на первом запуске: Windows — `HKCU\...\Run`, macOS — `SMAppService`,
  Linux — XDG autostart (`~/.config/autostart`).

## Отклонено

| Вариант | Цена (ноябрь 2026) | Почему нет |
|---------|--------------------|------------|
| Azure Artifact Signing | $9.99 в месяц | Расходы; иностранный сервис; для физлиц — только США и Канада |
| OV-сертификат подписи кода | ~$150–300 в год | Расходы |
| Apple Developer Program (Developer ID, нотаризация) | $99 в год | Расходы; иностранный сервис |

Подпись можно добавить позже, не меняя приложение: Velopack подписывает пакеты на этапе сборки
релиза.

## Последствия

- В CI добавляется задача релиза: `vpk pack` на каждой ОС. Секретов подписи нет.
- Каждая новая версия на Windows снова показывает SmartScreen: у неподписанных файлов нет
  накопленной репутации.
- Отчёты о падениях — локально, отправка только по согласию (ТЗ §4.4).
