# ADR-0024 — Дистрибуция и обновления

- **Статус:** Proposed — по итогам MVP-0, S0.9, ждёт решения владельца (связано с расходами)
- **Дата:** 2026-11-04

## Контекст

Desktop Edition ставится на Windows (MVP-1), macOS и Linux (MVP-2). Нужны установщик, автообновление
и подпись кода: без подписи Windows показывает предупреждение SmartScreen, а macOS не даёт открыть
приложение обычным двойным щелчком. Автозапуск — только по согласию (ТЗ §4.4).

## Решение

> Установщик и автообновление — **Velopack** на всех трёх ОС. Подпись: Windows — **Azure Artifact
> Signing** или **OV-сертификат**, macOS — **Apple Developer Program** (Developer ID + нотаризация).
> Linux — **AppImage** без подписи. До публичного релиза сборки для тестеров не подписываются.

| ОС | Формат | Обновление | Подпись |
|----|--------|-----------|---------|
| Windows | установщик Velopack (`Setup.exe`), ставится в профиль пользователя без прав администратора | Velopack, дельта-пакеты | Artifact Signing или OV-сертификат |
| macOS | `.app` и `.pkg` от Velopack, hardened runtime, `LSUIElement` | Velopack | Developer ID + нотаризация |
| Linux | AppImage от Velopack | Velopack (самообновляемый AppImage) | не нужна |

**Почему Velopack:** один инструмент и один формат релизов для трёх ОС, дельта-обновления,
установка без прав администратора, .NET SDK. Сборка релиза — одна команда `vpk pack` в CI.

**Linux, другие форматы.** `.deb` и Flatpak — позже, по запросу пользователей. Flatpak технически
возможен: X11 из песочницы доступен целиком, layer-shell у KDE и wlroots работает, секреты и
автозапуск идут через порталы. Но Flathub потребует явного разрешения на распространение: у
проекта нет лицензии.

**Автозапуск** — opt-in на первом запуске: Windows — `HKCU\...\Run`, macOS — `SMAppService`,
Linux — XDG autostart (`~/.config/autostart`).

## Стоимость (на ноябрь 2026, проверить перед покупкой)

| Что | Цена | Условия |
|-----|------|---------|
| Azure Artifact Signing, Basic | $9.99 в месяц (~$120 в год), 5 000 подписей | Для физлиц — только США и Канада; нужна платная подписка Azure; ключ в облаке, без токена |
| OV-сертификат подписи кода | ~$150–300 в год | Для всех стран; ключ на аппаратном токене или в облачном HSM удостоверяющего центра |
| Apple Developer Program | $99 в год | Нотаризация и сертификаты Developer ID входят в цену |
| Linux | $0 | — |

Итого: **~$220–400 в год** за Windows и macOS. EV-сертификат не нужен: он больше не даёт
мгновенной репутации в SmartScreen. Репутация у Artifact Signing и OV копится одинаково, с первыми
установками.

## Когда платить

- **MVP-1 (Windows, тестеры).** Сборки без подписи. Тестеры один раз нажимают «Подробнее →
  Выполнить в любом случае» в SmartScreen.
- **Публичный релиз Windows** — подпись обязательна. Выбор между Artifact Signing и OV зависит от
  того, на кого оформляется аккаунт: физлицо из США или Канады — Artifact Signing, иначе OV.
- **macOS** — Apple Developer Program нужен до первой раздачи кому-либо, кроме разработчика.
  Неподписанное приложение на Apple Silicon пользователь без Терминала не запустит.

## Последствия

- В CI добавляется задача релиза: `vpk pack` на каждой ОС, подпись секретами из окружения. Ключи и
  пароли подписи — только в секретах CI, никогда в репозитории.
- Обновления раздаются с GitHub Releases (Velopack умеет читать их напрямую) или со своего
  статического хостинга.
- Отчёты о падениях — локально, отправка только по согласию (ТЗ §4.4).
