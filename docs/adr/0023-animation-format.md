# ADR-0023 — Формат анимации Desktop

- **Статус:** Accepted (2026-11-04)
- **Дата:** 2026-11-04

## Контекст

Голубю на Desktop нужны клипы из словаря ТЗ §8.4. Они должны чётко выглядеть при любом масштабе
экрана (100–300 %), укладываться в бюджеты ТЗ §37 и подходить к стеку отрисовки из ADR-0021
(тонкое окно + SkiaSharp). Открытый вопрос Q5: стиль и художник.

Владелец выбрал стиль: **реалистичный чёрный сизый голубь**, походка с голубиным кивком, без
«наложенных» частей. Его согласовали на интерактивном прототипе.

## Варианты

| Вариант | За | Против |
|---------|----|--------|
| **Растровые спрайты в атласе** | Любая степень реализма, которую нарисует художник; вывод кадра — одно копирование из текстуры; стандартные инструменты (Aseprite, TexturePacker) | Память под атлас; под каждый масштаб — своя копия атласа |
| Скелетная анимация (Spine, DragonBones) | Плавность, мало памяти | Рантайм Spine для продукта требует платной лицензии; DragonBones не развивается; деформации по кадрам дороже по CPU; «резиновый» вид, от которого владелец отказался |
| Вектор, рисуемый каждый кадр | Резкость при любом масштабе | Сложная сцена каждый кадр — CPU; реализм ограничен вектором |

## Решение

> Клипы — **растровые кадры в атласе PNG** с описанием в формате **Aseprite JSON** (массив кадров,
> клипы в `meta.frameTags`) и секцией `meta.pigeon`: точка опоры и длина шага. Атлас запекается в
> **@1x, @2x и @3x**. В рантайме берётся наименьший атлас, который не меньше нужного масштаба, и
> кадр уменьшается при выводе (линейная фильтрация с mip-уровнями).

- **Формат совпадает с экспортом Aseprite.** Кадры из любого источника, который умеет этот
  экспорт, подключаются без изменений в движке.
- **Точка опоры (`anchor`)** — середина между стопами на земле. По ней кадр ставится в мир.
- **Длина шага (`stride`).** Кадр шага выбирается по пройденному пути: за `stride` логических
  пикселей проходит один цикл, поэтому опорная лапа не скользит при любой скорости.

**Источник кадров.** Художника в проекте не будет (решение владельца). Кадры берутся из двух
источников:

1. **Свои.** Процедурный генератор `tools/Pigeon.SpriteBake` — основной источник. Голова, шея и
   тело в нём — один силуэт, шея деформируется вслед за головой. Новые клипы и окрасы добавляются
   в генератор. Атласы — результат сборки, в репозиторий не кладутся.
2. **Из интернета** — только с лицензией, которая разрешает распространять ассет в закрытом
   продукте: CC0, public domain или лицензия с атрибуцией (например, CC BY). Лицензии с
   ограничением на коммерческое использование (NC) или требованием открыть код продукта (SA, GPL)
   не подходят. Источник, автор и лицензия каждого ассета записываются в `assets/THIRD_PARTY.md`.
   Ассеты, созданные генеративными моделями, не используются.

**Временный набор клипов для MVP-1:**

| Клип | Кадры | Частота | Повтор |
|------|------:|--------:|--------|
| `idle` — дыхание, моргание | 16 | 10 к/с | да |
| `walk` — шаг с голубиным кивком | 24 | 30 к/с, цикл 0.8 с | да, по пройденному пути |
| `peck` — клевок всем корпусом | 20 | 30 к/с | нет |
| `fly` — взмахи крыльями | 12 | 40 к/с | да |
| `sleep` — распушился, голова втянута | 8 | 4 к/с | да |

**Словарь ТЗ §8.4 → клип** (пока клипа нет, используется временный):

| Анимация §8.4 | Клип сейчас | Нужен свой клип |
|---------------|-------------|-----------------|
| Idle, LookAround, PerchBalance, Wake | `idle` | LookAround, Wake |
| Walk, Run, Hop | `walk` (Run — быстрее, Hop — пропуск кадров) | Hop |
| TakeOff, Fly, Flap, Land | `fly` | TakeOff, Land |
| Glide | `fly`, удержание кадра с раскрытыми крыльями | — |
| Peck, Eat, Drink | `peck` | Drink |
| Sleep, Sit, Puff | `sleep` | Sit с открытыми глазами |
| Groom, Coo, Startle, Poop | `idle` | все четыре |

**Локомоция ТЗ §8.1 → клип:** Walk, Run, Hop → `walk`; TakeOff, Fly, Glide, Land, FallRecover →
`fly`; Sit → `sleep`; Perch → `idle`.

## Замеры

Прототип оверлея Win32 + SkiaSharp в режиме `--sprite`: два монитора, 175 % и 100 %, эталонная
машина из ADR-0021. Данные — `docs/research/overlay/win32-skia-sprite-two-monitors.json`.

| Показатель | Значение | Бюджет ТЗ §37 |
|------------|---------:|--------------:|
| CPU, голубь сидит (всего CPU) | 0.3 % | ≤ 0.5 % |
| CPU, голубь в движении | 1.35 % | ≤ 2 % |
| Working set | 71–97 МБ | ≤ 150 МБ |
| Старт до первого кадра | 0.23 с | ≤ 3 с |

Клики, фокус, перелёт между мониторами и размер на обоих масштабах — как у векторного прототипа.

## Последствия

- **Память — основной расход.** Атлас @2x в памяти занимает около 42 МБ: кадры хранятся с пустыми
  полями. В MVP-1 кадры обрезаются по содержимому (`trimmed` в формате Aseprite) и плотно
  упаковываются, атлас грузится по клипам. Ожидаемый выигрыш — в 2–3 раза.
- **Скорость ходьбы связана с длиной шага.** Быстрая ходьба — это клип Run, а не ускоренный Walk.
- **Другие окрасы голубя** (ТЗ §5.1, внешний вариант) — палитра генератора или отдельные атласы
  художника; формат тот же.
- **Сторонние кадры** приводятся к тому же размеру кадра и той же точке опоры, что у генератора.
  Перед добавлением проверяются метаданные файла (автор, история редактирования).

## Реализация в продукте (M1.4)

- **Листы по клипам.** `tools/Pigeon.SpriteBake` пишет для каждого клипа и масштаба свой лист
  `{клип}@{N}x.png` и JSON Aseprite с одним `frameTag`. Кадры обрезаны по содержимому
  (`trimmed: true`, сдвиг в `spriteSourceSize`, поле 1 пиксель) и уложены полками. Весь набор @2x
  в памяти — 23 МБ вместо 40 МБ; продукт держит только клипы, которые играли последние 30 с —
  обычно 2–3 листа, около 12 МБ.
- **Тень рисует движок.** В кадрах её нет; параметры — в `meta.pigeon.shadow` (центр, радиус,
  сплющивание, непрозрачность в логических пикселях). Чем выше голубь над землёй, тем тень меньше
  и бледнее; на высоте 150 логических пикселей её нет.
- **Плавный масштаб.** При переходе на монитор с другим DPI размер голубя меняется за 0.35 с.
- **Старый атлас** `atlas@{N}x` — все клипы в одном листе, без обрезки, с тенью в кадре —
  генератор пишет для прототипов MVP-0.
- Код: `src/Pigeon.Desktop.Rendering` — сцена, листы, выбор кадра, отрисовка, общая для всех ОС.

## Клипы локомоции (M1.5)

Генератор добавил `sit` — сидит с открытыми глазами (Rest), `hop`, `takeoff` и `land`. Словарь
ТЗ §8.4 → клип теперь:

| Походка или намерение | Клип |
|-----------------------|------|
| Walk | `walk`, кадр по пройденному пути |
| Hop | `hop` |
| TakeOff, Land | `takeoff`, `land` |
| Fly, Glide, падение | `fly` |
| Sleep | `sleep` |
| Rest (Sit) | `sit` |
| Explore на месте | `peck`, раз в 1.4 с |
| остальное на месте | `idle` |

Весь набор @2x — 36 МБ без обрезки 62 МБ; в памяти продукта обычно 2–3 клипа, 12–16 МБ.
