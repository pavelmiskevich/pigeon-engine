# ADR-0008 — Jev

- **Статус:** Accepted; уточнено в ТЗ v1.1
- **Дата:** 2026-09-28, уточнение 2026-10-07

## Решение

> Jev — first-class high-level decision provider; не realtime controller.

Jev выбирает намерение; C# исполняет намерение. Jev не управляет физикой, кадрами, анимацией,
отрисовкой, позиционированием окон, циклами времени, транзакциями и вызовами ОС.

## Уточнение v1.1

- Jev — модель структурированных решений TypeSafe, доступная через OpenRouter
  (`typesafe/jev-1.13`, Decisions API `POST /api/alpha/decisions`). Она возвращает типизированный
  ответ с вероятностями по вариантам и не генерирует текст (ТЗ §17.1).
- Jev оформлен как советник `IDecisionAdvisor` поверх всегда присутствующего Autonomous
  (ADR-0015). Вероятности Jev смешиваются с оценкой Utility AI, а не заменяют её (ТЗ §17.4).
- Jev — удалённый провайдер: включается только при наличии ключа OpenRouter и согласия
  пользователя, получает контекст только после privacy-фильтра (ADR-0020).
- Версия модели в запросе фиксируется; снимок модели из ответа пишется в журнал.

## Последствия

- API в статусе alpha, поэтому адаптер изолирован в `Pigeon.AI.Jev` и покрыт контрактными
  тестами на записанных ответах.
- Задержка не документирована — замеряется в MVP-0 (S0.10).
- Стоимость показывается в Developer Mode по полю `usage.cost`.
